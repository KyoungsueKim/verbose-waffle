# 출력 파일 보관 정책

출력 요청이 끝나면 성공 여부와 관계없이 해당 작업의 PRN 파일을 삭제한다. 업로드 및 문서 등록이 진행되는 동안에는 PRN이 필요하므로 작업 종료 시 정리한다. 부분 변환 실패로 생성된 PRN도 같은 작업 ID로 정리한다.

`PRINT_RETAIN_JOB_FILES=true`는 업로드 PDF만 보관한다. `false`이면 PDF도 삭제한다. 정리는 해당 작업의 파일만 대상으로 하며 기존 파일이나 다른 진행 중인 작업 파일은 삭제하지 않는다. 프로세스 강제 종료나 파일 시스템 삭제 오류는 정상 종료 시 정리와 별개이며, 삭제 오류는 로그에 남긴다.
